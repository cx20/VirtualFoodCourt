16Batter

衣は、粒ではなく板と泡

coating — パン粉と天ぷらの衣は、形の作り方から違う

この章の3行まとめ
  • 揚げ物の衣を、等方的な（どの向きにも同じ）ノイズででこぼこにすると、から揚げか岩になります。
  • パン粉は寝ながら重なった薄い板、天ぷらの衣ははじけた泡（花）。でこぼこの作り方そのものが違います。
  • 揚げ色は形で決まります。ただし向きが逆で、パン粉は出っぱった破片の先が濃く、天ぷらは衣が厚い所ほど白い。

ここから第III部です。サンプルは最初の14本から大きく増えました。 増えたものの多くは、定食屋や麺屋に並ぶ料理です。とんかつ、エビフライ、コロッケ、天ぷら、 うどん、そば、ラーメン、スパゲッティ、焼きそば、カレー、肉じゃが、おでん、牛丼……。 第II部の4章で説明できることも多いのですが、それでは足りない難所が4つ出てきました。 衣・麺・汁・盛り付けです。最初は衣から見ていきます。

揚げ物は4本あります（とんかつ.js・エビフライ.js・コロッケ.js・天ぷら.js）。 うどん.js とそば.js にも、えび天と大葉の天ぷらが乗っています。 とんかつ.js の先頭には、外すと「茶色い直方体」になる要点が並んでいて、2番目がこれです。

「パン粉は『粒』ではなく『薄い板』。伸びた破片が寝ながら重なっている。 等方的なノイズで凹凸を付けると、から揚げか岩にしかならない」

03章のノイズは、どの向きにも同じ細かさでした。そういうノイズにしきい値をかけると、 丸い粒が散らばった模様になります。唐揚げの衣ならそれで合っています。 ところがパン粉は、パンを砕いた薄い破片です。破片は衣の表面に寝て、少しずつ向きを変えながら重なっています。 丸い粒では、何をしてもパン粉には見えません。

軸をつぶしたノイズを3枚重ねる

とんかつ.js は、ノイズを片方向に引き伸ばしています。横に細かく縦に粗いノイズにすると、 模様が横長の筋になります。向きを変えて3枚作り、各点でいちばん大きい値（max）を取ると、 向きの違う細長い破片が重なった模様ができます。

もうひとつの工夫が、しきい値の幅を狭くすることです。 smooth(0.500, 0.552, s) は、s が 0.500 から 0.552 に上がるあいだに 0 から 1 へ変わります。 幅が狭いので、破片の縁は崖のように立ち上がり、上面は平らになります。これが「板」です。 幅を広くすると縁がなだらかな山になり、丸い粒に戻ってしまいます。

実験 — 粒の衣 / パン粉の衣 / 天ぷらの衣

—

光は左上から当てています。3つのモードで違うのは「でこぼこの作り方」と「揚げ色を何から決めるか」だけです。 「揚げ色を形と結びつける」を切ると、色だけが形と無関係なノイズになります。 12章で見たのと同じく、柄の付いた布に見えるはずです。

天ぷらの衣は「花」で決まる

天ぷらの衣はパン粉とまったく違います。小麦粉を水で溶いた薄い衣が、油の中ではじけて固まったものです。 うどん.js の先頭には、こう書いてあります。

「天ぷらは『揚げ色の幅』と『花』。衣を一色で塗ると、形をどれだけ作り込んでも発泡スチロールになる。 花（はじけた薄い衣）が本体から独立して突き出していて、その先が白く飛んでいる——これが揚げ物」

天ぷら.js の衣は2段で作っています。まず、身の表面から法線の向きに衣の殻を張ります。 殻の厚みは一定ではなく、2枚のノイズで場所ごとに変えています。 次に、厚い所を選んで小さな泡（blob）と薄い花びら（crispyFlake）を生やします。 花はテクスチャに描いた模様ではなく、本体から突き出した実体です（09章と同じ考え方です）。

揚げ色の向きが、衣によって逆になる

12章で、焼き色は形と相関すると説明しました。揚げ色も同じです。ただし相関の向きが、衣によって逆になります。

衣濃くなる所淡くなる所コードの書き方
パン粉（とんかつ・コロッケ）出っぱった破片の先くぼみ・破片のすき間とんかつ.js の C_DARK に「あめ色（出っ張った破片の先）」、C_PALE に「くぼみ・生のパン粉が残った所」
天ぷら衣の薄い谷衣が厚い所・花の先天ぷら.js は厚みを正規化した値で DEEP → BASE → PALE を引く。KOROMO_PALE は「花の先。ほとんど白い」

パン粉の破片の先は薄くて油の中に突き出しているので、そこから先に色がつきます。 コロッケ.js にも「破片の先端ほど揚がって赤みが強く、破片のすき間（奥）は淡い黄金色」とあります。 天ぷら.js はその逆で、衣が厚い所ほど白く、薄い所ほど濃い色にしています。 どちらも「形から色を決める」点は同じです。 揚げ物を1本書いて、その揚げ色の式をもう一方の衣にそのまま流用すると、向きが逆なので失敗します。

断面が主役になる

とんかつは切って出す料理です。とんかつ.js の要点の1番目は「断面が主役」で、 パン粉の層（外は濃く内は白い）、バッターの細い線、脂の白い帯、肉、という4層が 3〜4mm の中に詰まっています。切り口は包丁が通った面なので平らで、 ぎざぎざなのは衣の縁の数mmだけです。

13章で、切り身は「表面」ではなく「切り口」だと説明しました。とんかつでも同じことが言えます。 切り口の肉には、筋に直交して切った繊維の断口が細かい斑点になって見えます。 とんかつ.js には「等方な網目を主役にして明るく出すと、断面が『白い落書き』に見える」という記録があり、 網目は細く淡くし、斑点を主にしています。 コロッケ.js とたい焼き.js も、割った断面（じゃがいもとひき肉、生地とつぶあん）を同じ関数の中で作っています。

つまずきポイント

揚げたパン粉は、思っているより光りません。 とんかつ.js の【対策】：「0.24〜0.58 では滑らかすぎる。揚げたパン粉は実測でおおむね 0.6〜0.85 のつや消し。油だまりでも 0.5 止まり」。 油で光らせたくなりますが、粗さを下げると濡れたプラスチックになります。 照りは全面に均一ではなく、くぼみ（油が溜まる所）だけ少し滑らかにします。

色・粗さ・凹凸の3枚は、同じ高さ場から作ります。 「3枚を別々のノイズで作ると、粒の位置がずれて『ざらざらの上にぼんやりした汚れが乗った』ように見える」（とんかつ.js）。 06章の3枚のテクスチャは、1つの高さ場から一緒に焼きます。

淡い色を広く置かない。 エビフライ.js は、参考写真から測った色を「いちばん淡い所でもうきつね色」の範囲に寄せています。 淡い色を広く置くと、粉を吹いたパンに見えるからです。

やってみよう
  1. 「等方ノイズ」と「パン粉」を切り替えて、どこで見分けがつくか（輪郭、上面、影）を言葉にする。
  2. パン粉のまま「揚げ色を形と結びつける」を切り、柄の付いた布に見えることを確かめる。
  3. 天ぷらで花の量を 0 にして、衣が発泡スチロールに見えるか確かめる。
  4. とんかつ.js で「C_DARK」を、天ぷら.js で「KOROMO_PALE」を検索し、揚げ色の向きが逆になっている行を探す。
